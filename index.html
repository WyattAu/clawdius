Clawdius

A formally verified, multi-provider AI coding agent

Clawdius is a next-generation AI coding engine built in Rust with a terminal UI, CLI, and multi-platform messaging gateway. It connects chat platforms to a formal-verification-backed code generation engine, supporting Anthropic, OpenAI, Google, xAI, Mistral, DeepSeek, Ollama, ZAI, and OpenRouter with automatic retry. Lean4 proofs verify sandboxing, concurrency, and security invariants.

Features

  • Multi-provider LLM with automatic retry
  • 60 FPS terminal UI (25+ commands)
  • Agentic sprint execution and auto-fix
  • 9 messaging platform adapters
  • Lean4 formal verification (209 theorems)
  • JIT sandboxing (Wasmtime WASM)
  • Session management with auto-compact
  • Architecture drift and debt analysis
