Analyze codebase for architecture drift and technical debt

Usage: clawdius analyze [OPTIONS] [PATH]

Arguments:
  [PATH]  Path to analyze (file or directory) [default: .]

Options:
      --drift                Analyze for architecture drift only
      --debt                 Analyze for technical debt only
  -f, --format <FORMAT>      Output format (text, json) [default: text] [possible values: text, json, stream-json]
  -o, --output <OUTPUT>      Output file path (prints to stdout if not specified)
      --severity <SEVERITY>  Minimum severity level to report (low, medium, high, critical) [default: low]
      --exclude <EXCLUDE>    Exclude patterns (comma-separated)
  -h, --help                 Print help
