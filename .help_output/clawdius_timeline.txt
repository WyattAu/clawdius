Manage file timeline and version history

Usage: clawdius timeline <COMMAND>

Commands:
  create    Create a timeline checkpoint
  list      List all timeline checkpoints
  watch     Watch for file changes and auto-create checkpoints
  rollback  Rollback to a checkpoint
  diff      Show diff between two checkpoints
  history   Show file history
  delete    Delete a checkpoint
  cleanup   Clean up old checkpoints
  help      Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
