Manage local LLM models (Ollama)

Usage: clawdius models [OPTIONS] <COMMAND>

Commands:
  list     List available local models
  pull     Pull a model from registry
  health   Check Ollama server health
  current  Show current model
  help     Print this message or the help of the given subcommand(s)

Options:
  -H, --host <HOST>  Ollama host [default: localhost]
  -p, --port <PORT>  Ollama port [default: 11434]
  -h, --help         Print help
