Manage project memory (CLAWDIUS.md)

Usage: clawdius memory <COMMAND>

Commands:
  show          Show project memory (CLAWDIUS.md + learned entries)
  learn         Learn a new memory entry
  instructions  Set project instructions
  list          List learned entries by category
  clear         Clear learned entries
  init          Create or update CLAWDIUS.md file
  help          Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
