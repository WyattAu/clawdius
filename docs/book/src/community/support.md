# Support

## Reporting Issues

Bug reports and feature requests should be filed on the [GitHub issue tracker](https://github.com/WyattAu/clawdius/issues).

When filing a bug report, include:

- Clawdius version (`clawdius --version`)
- Rust toolchain version (`rustc --version`)
- Operating system and architecture
- Minimal reproduction steps
- Relevant log output (enable with `RUST_LOG=debug`)

## Security Vulnerabilities

Do not report security vulnerabilities via public issues. See [SECURITY.md](https://github.com/WyattAu/clawdius/blob/main/SECURITY.md) for the responsible disclosure process.
